# Documentation and content-audit agent contract

This file supplements the root `AGENTS.md` for work under `docs/`.

## System strategy evidence

Before documenting, approving, or revising any system-authored strategy in a content audit, read and follow `docs/system-strategy-evidence-standard.md`.

The evidence bar is intentionally strict. Do not approve a system strategy when its only support is a nearby mechanism, a theoretical inference, an uncontrolled pre/post study, a small pilot, a correlational association, or research on a materially different intervention. Prefer direct intervention evidence from high-quality systematic reviews/meta-analyses, evidence-based guidelines, or well-designed controlled human studies.

If a strategy does not clear that bar, omit it rather than preserving it for deck size or variety. Record important evidence limitations internally. Production content still follows the complete-package approval gate in `docs/content-evidence-review.md`.

Every approved system strategy must retain the standardized visible **`Supporting source ↗`** link. Genuine user submissions remain governed by protected user-provenance rules and do not require scholarly citations.
